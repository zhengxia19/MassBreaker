# 游戏画面、视觉资源与反馈详细规格

**文档编号**：MB-VIS-014｜**状态**：视觉实现设计就绪，正式代码与真机视觉验收尚未完成。

## 1. 目标与权威来源

本项目的视觉特色是**真实可辨识的 96×160 微型砖阵、固定通道与奖励产生的多球**，而不是铺满大面积色块或用爆炸粒子替代球体。游戏物理仍只有一套；图形表现不得修改碰撞半径、砖格坐标、生命或球速。

- 视觉参数（UI 参考框、色板、主题、效果时长）：[`assets/config/visual.json`](../assets/config/visual.json)，这是**实现数值唯一来源**。
- 游戏数值、命中面积：[`assets/config/gameplay.json`](../assets/config/gameplay.json)。例如球半径 `0.17`、砖格 `0.25`、挡板 `4.5×0.35`、掉落物碰撞盒 `0.8×0.4`。视觉配置不覆盖这些值。
- 源关卡：[`levels-src/`](../levels-src/)；运行时世界必须从 [`assets/levels/`](../assets/levels/) 读取。
- 本文件只规定 **V1 可实现的基础资源和反馈**，不新增道具、移动机关、角色动画或复杂主题商城。

## 2. 参考画板与坐标精度

**360×800 是逻辑 UI 参考单位（不是设备 px）**。游戏物理世界为 `24×40`，默认完整视口 `x=0..360, y=94..694`，即 `15 UI 单位/世界单位`。设备实际可用区域先扣除刘海、手势和系统安全区，再对**完整世界 + HUD + 操作区域**等比适配；世界不可裁剪或拉伸，UI 按锚点布局。等比缩放后的微型格距 `0.25×15=3.75` UI 单位、球体物理直径 `0.34×15=5.1` UI 单位。**显示 DPI 更高只是图形像素更多，不改变任何物理尺寸。**

| 参考矩形（x0,y0,x1,y1） | 元素 | 说明 |
|---|---|---|
| `[12,10,348,84]` | HUD | 关卡名称、生命、分数、暂停按键，暂停命中框至少 44×44 UI |
| `[0,94,360,694]` | 游戏世界 | 完整 24×40，无裁剪；默认显示格宽 3.75 UI |
| `[12,698,348,733]` | 状态栏 | 活动球数与剩余目标砖块数，仅使用 `SessionSnapshot` |
| `[12,744,348,792]` | 操作区可视框 | 挡板水平位移、READY 时轻点发球；**实际命中范围 `[0,736,360,800]` 高 64 UI 单位**，短屏等比缩放仍应可操作 |

视口公式：`scale=min(worldRect.width/24, worldRect.height/40)`；`screen=viewportOrigin+world*scale`；坐标变换逆运算对输入和渲染共用，同一帧只读取一份 `ViewportTransform`。物理世界 y 向下，纹理与 GL UV 的上下翻转在 `Renderer` 一处处理，禁止散落到关卡 JSON。

## 3. 砖块视觉和可辨识性（最重要）

### 3.1 与玩法一致的状态表

| 格种 | Shader 表现 | 视觉区别 | 玩法语义 |
|---|---|---|---|
| `.` | 世界底色，低对比方格可选 | 明显空洞 | 无碰撞 |
| `1` | 当前主题主色实心小矩形 | 清晰色面 | 1HP |
| `2` | 橙色实心小矩形 + 顶缘亮线（缩小时仅亮度） | 与 1HP 区别不仅靠颜色 | 2HP；扣到 1HP 后亮度降低 |
| `3` | 粉红色实心小矩形 + 2–3 条微刻纹（缩小时只保留亮度分层） | 比 2HP 进一步加重 | 3HP；HP2/HP1 根据剩余 HP 下调细节 |
| `B` | 高亮紫色微砖 + 中心亮点，**砖内不写“+3”** | 微格太小，文字不可读；靠紫色+亮点区分 | 毁掉后掉落 +3 道具 |
| `#` | 灰蓝色不发光砖块，可按邻近格形成墙体连续感 | 只做视觉纹理，不改碰撞盒 | 不可破坏 |

严格使用 `GL_RGBA8UI` 的 `type/hp/palette/flags` 以及关卡 `theme` 选色。`hp` 是当前耐久度，不能从击中动画或 GPU 颜色推算玩法 HP。`type=BONUS` 被摧毁时才创建道具，游戏显示帧可独立绘制落下的 `+3` 标签。

### 3.2 像素呈现细则

- Shader 以世界坐标算 `cell=floor(worldPos / 0.25)`；取 `0..95 × 0..159`，用 `texelFetch` 精确读取对应 texel；禁止双线性采样或模糊游戏砖格。
- `visual.json.units.brickGapWorld=0.03` 是总视觉留缝宽度，即每边 `0.015`；视觉完整格仍对应 `0.25×0.25` 的碰撞体。保留连续墙体的灰色主轮廓，**不把视觉圆角当作物理圆角**。
- 放大截图的微砖图案可含光泽线；在实际不足 6 个**物理像素**的砖格上自动退化为清晰色块，避免闪烁/摩尔纹和毫无意义的低像素文字。
- 当前 6 个关卡主题使用 `visual.json.themes` 六种颜色；HP2、HP3、BONUS、WALL 具有跨主题一致的识别色，不能依主题变得与背景同色。
- 砖块消失后立刻在 GPU 状态纹理上变为 EMPTY；动画是**覆盖层**而非要求物理继续保留该砖，保证碰撞/视觉一致。

## 4. 球、挡板、道具、背景

| 元素 | 正式形状 | 尺寸依据 | 动画规则 |
|---|---|---|---|
| 弹球 | 不透明亮白/微青色实心圆，外侧弱青色晕 | **内核半径严格等于**物理 `0.17`，光晕可超出但不参与碰撞 | 可选低亮度 2–4 个历史位置的短尾迹；尾迹不用于推断速度 |
| 挡板 | 一条青色低圆角横杆，细亮上边缘 | 与物理矩形 `4.5×0.35` 对齐；装饰发光不改变 AABB | 命中 75 ms 轻闪，不能因状态动画改变真实挡板中心 |
| 未拾取 `+3` | 紫色小牌，白色清晰 `+3` 标志 | 碰撞仍是 `0.8×0.4`；**可视尺寸**为 `1.6×0.9` 世界单位，以当前位置为中心，不参与拾取计算 | 竖直按 `6` 世界单位/秒掉落；由 `ItemRenderState` 绘制 |
| 固定墙 | 灰蓝石质小砖或相邻连通的灰条 | 物理网格 `#` 位置与碰撞完全相同 | 不闪烁，不被击碎，不额外生成大量粒子 |
| 世界背景 | 深蓝黑底色，低对比每 8 格辅助线 | 只渲染世界区域 | 对比度保证球和破口明显；无背景动态拖影 |

游戏画面必须逐格呈现真实砖块及清除后的洞。`design/ui/final/03_gameplay.png` 采用真实 L003 地图；`03_gameplay_multiball.png` 采用真实 L028 地图。两图中的球位、分数与掉落物位置是**人为展示用示意**，不是真正物理模拟截图。

## 5. 可执行的动效与音画反馈矩阵

视觉动画仅由事件驱动，渲染阶段**不回写**游戏逻辑。时间单位毫秒基于展示时钟；暂停/终态冻结世界效果，面板的有限淡入/按钮反馈仍可完成。动画完成后不再周期唤醒，后台停止所有视觉时间；恢复不回放旧事件。

| 触发 | 视觉表现 | 持续时间 | 事件优先级 / 合并 |
|---|---|---:|---|
| `BrickHit`（仅当事件 `value>0`，HP 未归零） | 该微格亮度上升后恢复 | 65 | 同显示帧可按位置合并；HP 以最新快照为准 |
| `BrickDestroyed` | 对应格立即变空，短白闪最多微量碎屑 | 95 | 每显示帧最多新建 `24` 个粒子组，另受总存活上限限制；计分/目标数绝不丢 |
| `PaddleHit`（算法 §7.1 正式枚举） | 挡板上沿轻闪 | 75 | 同帧可合并为一次 |
| `ItemCollected`（唯一拾取事件名称） | 掉落物消失，**不在此事件固定显示 +3 球** | 当步 | 拾取结果由随后同 ItemId 的 BallsSpawned 决定 |
| `BallsSpawned` | 真正新增的球从挡板附近扇形出现；上方弹出与 `value/overflowScore` 对应的 0–3 球补偿提示 | 160 | 即使 value=0 也显示补偿；新实体不跨出生插值 |
| `BallLost` / `LifeLost` | 仅丢最后球时显示生命变化与准备状态 | 150（建议） | 不遮挡重新发球的主位置 |
| `LevelWon` | 保留最终场景，约 180 ms 淡入胜利面板 | 180 | 仅发出一次；优先于同 tick 失球 |
| `LevelLost` | 180 ms 淡入失败面板 | 180 | 仅发出一次 |

`maxImpactParticlesPerDisplayFrame=24` 是**视觉预算**，不是每帧允许的碰撞数。即使有数千次碰撞也要全部在物理层处理，只有粒子和声音做采样/限流。命中音效至多按 `gameplay.json.render.maxHitSoundsPerDisplayFrame=4` 聚合；拾取/通关/失球事件有更高声音优先级。设置页关掉特效/声音，不影响碰撞和计分。

### 5.1 容量补偿视觉

实际奖励只消费 `BallsSpawned.value/overflowScore`；道具牌的 `+3` 是标称值。`ItemCollected` 不驱动固定三球动画。

| 实际新增球数 | 额外得分 | 实际弹字 | 视觉处理 |
|---:|---:|---|---|
| 3 | 0 | `+3 球` | 展示三颗新球 |
| 2 | 50 | `+2 球 · +50 分` | 展示两颗新球，显示补分 |
| 1 | 100 | `+1 球 · +100 分` | 展示一颗新球，显示补分 |
| 0 | 150 | `球数已满 · +150 分` | 不生成球体视觉，仅显示补分 |

同帧多次拾取按 ItemId 分别反馈；核心分数与球数不受动画合并影响。新增球使用当前出生位置，不跨出生插值；若其已在后续 tick 离场，不凭事件重建实体。

### 5.2 有界视觉工作量

预算唯一来源为 `visual.json.effects`，不影响玩法事件：

| 字段 | 默认值 | 实施要求 |
|---|---:|---|
| maxImpactParticlesPerDisplayFrame | 24 | 每个实际显示帧最多新增 24 组，超额只省略粒子反馈 |
| maxLiveParticleGroups | 144 | 全局同时存活粒子组上限，预分配组池；不是每球各一份预算 |
| maxParticlesPerGroup | 4 | 每组最多 4 个粒子，最多 576 个活动粒子 |
| maxParticleLifetimeMs | 95 | 粒子到期回收，关闭效果时停止更新和实例上传 |
| maxTrailPointsPerBall | 4 | 每球可选尾迹点上限；按活动球有效长度处理，关闭时不维护尾迹 |

以上为已启用效果的上限，须在 T12 验证视觉效果及耗时，不是实测最优值。可选尾迹未启用时不实现尾迹池/更新路径；有配置上限不代表必须实现该可选效果。热压力上升按尾迹、粒子、光晕顺序降低可选效果；基础球芯、砖格和 HUD 保持可辨识，不自动降低物理频率或有效球数。

字形在加载/页面切换预热；HUD 文本只在值改变时更新布局，静态 UI 复用几何。命中闪光限于对应格或挡板，绘制裁剪到有效世界/UI 区域，避免以全屏透明层叠加每个命中。音效预加载并按显示帧聚合；静音停止无用混音，不能为音频回调刷新静止页面。

## 6. 场景层次和混合模式

由后往前：`WorldBackground → GridMicroBricks → SolidWallHighlight → HitFlash/SmallParticles → BallTrails → BonusItems → BallCores → Paddle → HUD → ScreenOverlay → ModalDialog`。球的亮芯应始终压在破砖粒子之上，确认弹窗置顶并阻断触控穿透。粒子合成使用低强度 alpha，避免数百球时满屏白光。暂停或切后台冻结场景渲染动画时钟。

渲染按 [`12_CORE_ALGORITHMS.md §3.4`](12_CORE_ALGORITHMS.md) 的 `FramePacket` 消费，HUD 只能读取 `frame.currentTick.hud`：同显示帧多个 tick 聚合砖块变化并整张纹理最多更新一次；球、板、掉落物使用连续 tick 快照插值。FramePacket 由收集器长期持有，本次只读借用在 releaseFrame 前同步消费；不得保存过期引用。Renderer 在每次服务轮同步采纳 CPU 反馈/复位，实际 GL 提交只在显示到期时执行。

零 tick 帧也可能收到 `SessionReset`，须清除旧尾迹并刷新全量砖纹理；无新事件时不得重播声音。终态 tick 的事件保留。过载暂停只叠加面板与说明，保持当前场景状态。

## 7. 全部 8 页 UI 的正式表现基线

`design/ui/final/01_home.png` 至 `08_tutorial.png` 为**页面设计稿**，在既有布局基础上应用相同色板和组件风格。其接口及屏幕命中优先级仍见 [`10_UI_UX_DESIGN.md`](10_UI_UX_DESIGN.md)。

| 页面 | 已明确的视觉和操作 | 特殊状态 |
|---|---|---|
| 首页 | 黑蓝底、标题双层、真实地图局部预览、3 个大按钮 | 首次按钮“开始游戏”；已有进度“继续游戏” |
| 选关 | 章节栏、两列卡片、从真实 JSON 生成的布局预览、锁/星状态 | 已完成有星；未解锁不可点击 |
| 游戏 | HUD/真实微砖/通道/球/板/+3/状态栏/触控区 | READY 发球提示、PLAYING 数据实时更新 |
| 暂停 | 游戏场景暗化，居中面板三个操作 | “重试”“退出”若有进度损失先确认模态 |
| 通关 | 结果覆盖层，星级/得分、下一关/重玩/选关 | L030 改为“返回关卡” |
| 失败 | 结果覆盖层，得分/原因、重试/选关 | 不提示观看广告复活 |
| 设置 | 音乐、音效、震动开关，本地持久化 | 不支持震动时显示禁用 |
| 首次提示 | 挡板滑动与轻点发球说明，首次 +3 的提示 | 模态弹窗拦截底层按钮，不允许穿透 |

控件基本状态（默认/按下/禁用/聚焦）不得单纯依靠颜色；禁用按钮降低对比度并禁止激活，按下态轻微改变边框亮度。触控命中矩形与视觉矩形共用 UI 安全区变换。游戏中不放“加速观看”或其他已排除功能。
